# 公用演示配置与 ECA 材料参考

v0.72.2 起，空工作区也能查看三份作息演示模板和已授权 ECA 示例。它们用于理解配置与建立自己的版本，不会自动套用到已有建筑或方案。

## 作息参考库

在“导入建筑模型”窗口，可先展开“公用演示配置”查看参数；源库读取完成后，在房间配置来源中明确选择模板或保留源配置。每个选项均显示人数、照明、设备的数值范围和单位，展开详情可见全部 24 小时工作日及周末作息。已登记建筑的原房间配置另列一组，实际每间值不会误称为面积密度。

三份模板均为 Zhao Bencheng / 建筑热环境工作台原创的流程演示数据（版本 1.0），不是规范值、实测值，也不是办公、住宅等具体用途的推荐值。

| 参数 | 所有模板共同演示值 |
| --- | --- |
| 人数密度下限 / 上限 | 0 / 0.1 人/m² |
| 照明功率密度下限 / 上限 | 0 / 8 W/m² |
| 设备功率密度下限 / 上限 | 0 / 10 W/m² |
| 人员显热 | 100 W/人 |
| 照明入室得热比例 | 1 |

| 模板 | 工作日 | 周末 |
| --- | --- | --- |
| 日间使用 | 08:00–18:00 比例为 1，其余为 0 | 全天 0 |
| 夜间使用 | 18:00–次日 08:00 比例为 1，其余为 0 | 同工作日 |
| 连续使用 | 全天 1 | 全天 1 |

人数、照明和设备共用上述时段。每小时实际值 = 下限 + 比例 ×（上限 − 下限）；密度值再乘目标房间面积。例如 100 m² 房间，在启用小时对应 10 人、800 W 照明和 1000 W 设备。完整数组见 [usage-profiles.json](../resources/starter-library/usage-profiles.json)。

选择模板会替换人数、照明、设备及其作息和上述得热参数；人员潜热与房间是否接空调保留源库。空调可用时段和温控阈值仍需在导入表单中另行选择。转换会记录所选配置、版本与文件校验值；导入后可继续编辑并保存建筑配置版本。请按实际项目核对再使用。

## 材料参考

“材料库 → 研究材料与版本”直接显示“ECA（热阻可调示例）· 内置只读”。参数来自原有 [ECA.json](../examples/materials/ECA.json)，此次没有改动其数值。

点击“复制为我的材料”后可修改名称、蓬松/压缩热阻和 A/B 两组光学参数参数，再保存独立版本。内置示例保持不变；选入方案需要另行预览、确认并保存方案版本。普通构造材料页仍从已登记建筑读取，不将 ECA 当作任意构造的通用标准材料。

这些参考数据采用 CC BY 4.0，署名 Zhao Bencheng。Drawing26 和第三方资产原许可保持不变。演示库不会放宽 ACCDB 几何检查；Drawing26 的通用导入门洞限制继续适用，公开示例仍走专用模板入口。
