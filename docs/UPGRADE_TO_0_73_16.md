# 升级到 v0.73.16 公开预览版

向导支持从 v0.72.2、v0.73.11 至 v0.73.15 以及 v0.73.14-rc.1 至 rc.9 在原路径升级。将新包解压到旧平台目录之外，保存页面上的编辑，等待当前计算和导出完成。接通登记过的外置结果盘。

1. 在新包目录双击 `Upgrade Workbench.cmd`，选择 `1`，输入旧平台目录。该目录应包含 `Start Workbench.cmd`。
2. 向导会检查备份路径能否容纳最深的文件。屏幕出现建议目录时，回车即可采用。若两个建议目录都太长，请指定短目录，并为平台及已登记的外置结果预留备份空间。
3. 核对将更新的版本和备份位置，输入“升级”。完成后从原路径启动平台。
4. 进入“计算队列”，从一个已完成批次打开“查看计算结果”，点地点查看负荷。有复核的地点还可查看原警告、采用结论及其适用范围。

已知历史程序的完整文件指纹随包登记，工作台据此读取旧结果。需要继续执行旧预算时，从原保存版本重新准备，核对地点、时段、步长和待算项数，再确认提交。

若要恢复，重新打开升级助手，选择 `2`，输入含 `BACKUP.json` 的备份目录。恢复助手会先保存升级后的现场，再回到备份状态。[安装说明](INSTALL.md)
