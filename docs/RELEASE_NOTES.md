# v0.73.16 建筑热环境工作台公开预览版

- **比较不同计算时段。** 全年结果和短时段结果可按双方都完整覆盖的自然月比较，图表注明各自的起算和预热条件。逐日负荷可进一步查看房间差异。
- **按地区出图。** 中国省级地图按气象站位置归属，采用 2022 年边界。标准图和等积双图均可导出可编辑的 Origin 工程，数据包附重绘教程。需要导出工程时，可在页面检查绘图 Python 与 Origin 接口。
- **从对比继续设计和计算。** 对比集中的追问可回到已有设计及其预算。双因素设计可查看行、列差值，选择工况扩展到其他地点，并逐地点查看输入准备进度。
- **核对墙体响应。** 可为多面墙设置测点，查看组合材料的分层和表面光学响应，并联读墙温、室温和空调状态。已有数据可导出为简表和带可编辑图表的工作簿。
- **升级和历史记录。** Windows 升级向导会检查备份路径长度，必要时自动建议短目录。已核验的历史程序版本可读取原负荷、补算和复核说明。旧预算可从原方案重新准备，提交时按当前程序核验。
- **结果页面。** 铺设范围对照明细可直接打开图表。刷新补算状态时，同步更新当前明细。长页面和弹窗中的操作提示更容易看到。

已有工作区请将新包解压到单独目录，从新包运行 `Upgrade Workbench.cmd`。[升级与恢复](https://github.com/YiXueYingCheng/building-thermal-workbench/blob/v0.73.16/docs/UPGRADE_TO_0_73_16.md) · [首次安装](https://github.com/YiXueYingCheng/building-thermal-workbench/blob/v0.73.16/docs/INSTALL.md)
