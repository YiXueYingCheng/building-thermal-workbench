# v0.72.0 · 建筑热环境工作台公开预览

首次公开预览，邀请未参与开发的使用者从 GitHub 下载、安装并完成示例，反馈安装与使用体验。

包含 Windows 本地工作台、Drawing26 建筑、ECA 可调热阻材料、两日固定 R/C、两日热阻反馈和31日翻面对照的复现入口与验收结果。气象通过原站下载；Python 环境、EnergyPlus 和数据库驱动由使用者另行安装。

首次使用建议阅读包内 `docs/FIRST_TRIAL.md`，先完成两日反馈，再做固定蓬松对照与导出。软件代码采用 MIT，自有文档、样例和结果采用 CC BY 4.0；destep、地图等第三方的原署名和许可保留。

当前已完成开发机的新 Python 环境及独立解压目录验证，43 项自检、7 个接口检查通过，两日反馈复算与此前一致。第二台电脑的安装与使用反馈将在公开后收集。

已知限制：Drawing26 通用导入因一扇门的两侧边界问题停止，示例使用既有专用模板；结果反映指定模型与时段，不等同于全年节能率或设备电耗。详见 `docs/KNOWN_ISSUES.md`。

推荐下载附件 `building-workbench-v0.72.0.zip`，可用相邻 `.sha256` 文件核对完整性。反馈可在仓库 Issues 使用“首次试用反馈”模板。
