# v0.73.14 建筑热环境工作台公开预览版

- **计算内存**。工作台在准备新清单时合并文件内容与读取设置相同的只读作息，独立控制的作息保留各自定义。五层建筑的 1 月、1 分钟热阻调节算例中，704 条作息合并为 56 条，求解器驻留峰值从 3.61 GiB 降至 0.90 GiB。按原作息名核对的 50,259 条结果一致。实际节省量取决于模型中重复作息的数量。
- **材料与外墙**。普通导入建筑和 Drawing26 可以逐墙选择铺设范围及热阻反馈组。支持撤除研究材料、回到原构造，并可组合表面光学切换与热阻调节。对照结果列出新增和撤除的墙段；全年严格配对、仅扩大铺设且其余控制一致时，可查看每平方米新增铺设面积对应的显热需求变化。
- **预热与单地点补算**。可查看房间预热温差、隔日重复等趋势。可对失败地点缩短步长补算，通过后由用户确认并入原批。对照页支持单地点同一步长加算，或逐地点确认跨步长豁免。导出分别列出严格配对和含豁免的汇总。
- **队列与预算**。内存预算区分驻留峰值、提交量和共享作息模型，可重新计算已取消项。手动独占启动须先确认内存不足等风险，同时只运行一个算例。
- **结果与导出**。批次数据包可选保存频率、冷热需求、室温、作息，以及已启用并有原始记录的热阻或光学状态。共享作息支持按原名查读，批量导出随附名称对照表。

新安装请下载 `building-workbench-v0.73.14.zip` 和对应的 `.sha256` 校验文件。已有 v0.72.2、v0.73.11 至 v0.73.13 或 v0.73.14-rc.1 至 rc.9 的用户，请等当前批次结束，将新包解压到独立目录，从新包双击 `Upgrade Workbench.cmd`，按向导在备份后升级原工作区。
