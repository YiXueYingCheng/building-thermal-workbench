# v0.73.15 建筑热环境工作台公开预览版

- **保存的比较可以独立读取。** 升级后，工作台为每个已有对照保存双方当时使用的方案版本。整理旧示例后，仍可查看配置差异、逐地点结果及其核验依据。
- **从对照设计准备算例。** 在设计格中优先查找满足条件的已保存版本；缺少版本时可预览派生工况，确认后再填回原格，从该版本进入模型核对与预算。
- **对比集与方案清理。** 可以收录和移出对照，按成员查看月度负荷。清理预览列出引用方、涉及的版本和可执行的解除操作，支持重开预览。
- **气象库。** 导入气象可选择保存副本或引用已有文件，在管理页统一查看来源与可用状态。多套工作台可共用同一份气象文件。
- **结果读取与导出。** 重开批次和对照时可复用已核对的结果。逐日导出提供整栋建筑的冷热需求，便于直接与月度表核对。
- **逐墙核对材料。** 可在平面图中选择墙段，查看已保存的材料状态、朝外面，以及该地点实际生成模型中的热阻和表面光学参数。
- **材料与示例。** 材料库收录 C18 相变层和 PE 光谱层的建模参数及假设。普通建筑导入示例采用修补版 Drawing26。

已有工作区可从新包运行 `Upgrade Workbench.cmd`，完成备份后在原路径升级。[安装说明](https://github.com/YiXueYingCheng/building-thermal-workbench/blob/v0.73.15/docs/INSTALL.md) · [升级与恢复](https://github.com/YiXueYingCheng/building-thermal-workbench/blob/v0.73.15/docs/UPGRADE_TO_0_73_15.md)
