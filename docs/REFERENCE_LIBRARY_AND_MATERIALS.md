# 公用库、材料与气象下载

适用范围：v0.73.11 公开预览版；参考库公开范围见 [逐项清单](REFERENCE_DISTRIBUTION_REVIEW.md)。材料的光学输入、可见光继承、密度辅助和状态名称用法见 [材料参数说明](MATERIAL_INPUTS.md)，自动化调用见 [Agent 接口说明](MATERIAL_AGENT_API.md)。

## 公用参考库

顶部“公用参考库”保留早期 Excel 库的名称、来源编号和数值：28 条日作息、48 条全年时刻表、8 种房间配置、897 条材料参考、47 套构造。

- 日作息可以复制为自己的版本，在房间配置的日计划选择器选用。人数、照明与设备功率上下限需要分别核对。
- 全年时刻表保留完整 8760 小时，可按日查看和导出 CSV；不把季节或特殊日强行合并成普通工作日／周末。
- 8 种能够精确还原的房间配置加入 ACCDB 导入的配置来源，与 3 种透明演示模板并列。只映射人数、照明、设备、显热及对应作息；原空调归属与四阈值温控保留。参考类型不是现行规范推荐值。
- 材料参考可复制到材料表单。名称、导热率、密度、比热和原始来源随表单保留。缺失厚度与光学参数须补齐；不根据反射率擅自推算吸收率。
- 构造可查看每层名称和物性，复制为“我的构造版本”，修改厚度及物性后保存新版本。旧版不变。

采用构造：先打开可编辑的研究方案，在“我的构造版本”选择版本、外墙或屋面范围，明确原层号正向／反向哪个是室外到室内，并勾选沿用原内外表面光学。预览列出受影响的表面和层序；确认后只进入方案草稿，仍需保存方案版本、核对输入。

首批只接入不透明外墙／屋面，保留几何、边界、内外表面光学及未选构件。每层要求真实厚度、导热率、密度和比热，不能把空气间层当作实体层。有局部层编辑、活动保温层或旧 ECA 动态适配时会拒绝冲突组合。已采用的构造固定引用具体版本；在库里编辑后须明确重新选用。方案顶部可以预览撤销库构造指定。

作者已授权作息和公用配置参考快照随平台公开。原数据来源与第三方条件保留；建筑源文件、Excel 原文件和独立用户研究材料_10mm未新增收录，既定 Drawing26/ECA 示例保留。范围与排除项见 [随包清单](REFERENCE_DISTRIBUTION_REVIEW.md)。

## 新建材料

新建、复制和编辑使用统一表单，先选“仅表面光学”“计入热阻与蓄热”或“仅计热阻、不计自身蓄热”，再填状态与物性。薄膜/气凝胶等材料形态与计算方式分开记录。详细参数、限制及采用流程以 [材料参数说明](MATERIAL_INPUTS.md) 为准。

不计蓄热仅针对新增层；原墙体继续蓄热。无蓄热材料当前不能通过新登记入口进入可调热阻工况。实体材料即使计入蓄热，通用入口仍按所选固定状态计算；旧 ECA 特定示例保持其原接法。

## 气象批量下载

1. 打开顶部“气象下载”，选中国 34 地区、全球可用类别或逐项勾选。中国预设每地区选取一个站点，不代表全省气候。
2. 全球界面列出 30 个气候类别槽位；历史来源清单现有 29 类可下载，Csc 明确缺项。完整清单共 107 项：34 个中国预设和 73 个全球候选。旧分类标签仅作为历史检索信息；保留替代站点、ERA5/PVGIS 等原说明，不作新的分类认证。
3. 指定自己的下载文件夹，再开始。程序依次下载、核对已登记校验值并检查 EPW 逐时质量；不下载来源清单之外的地址。重复文件内容匹配时复用，冲突文件不覆盖。
4. 可以“完成当前文件后停止”，之后重试失败或继续未完成项。服务重启后未完成批次标记中断，需明确继续。质量异常文件保留待核对，不自动登记。
5. 查看来源和质量提示，勾选确认后登记通过检查的地点。选择“保存工作区副本”或“仅引用原文件”。单文件和文件夹导入也提供这两项。多个工作区可共同引用一个下载目录，建议使用简短的英文路径。登记后请在方案“范围”选用。

在“工作区配置 → 管理已导入气象”查看每个地点的保存方式与实际读取路径。“核对文件”会逐项验证内容。仅引用的文件需要一直保留在登记位置，或通过来源位置管理重新定位到内容相同的文件。已有副本仍可使用。

天气文件从提供方原站获取，不随此过渡更新附带；文件校验不能代替对适用年份、站点代表性和使用条件的核对。保留原数据来源与引用，不变更其许可。

## 验证范围与旧数据

独立副本完成材料、参考库、构造与下载检查；8 次 Drawing26 长沙 1 月 1—2 日的实际 EnergyPlus 计算通过。其中以原光学参数登记仅光学薄膜，汇总结果与基准完全一致。构造替换保持房间、开口和几何计数；构造与新材料组合也通过计算。

这些是功能与输入流程验证，不是材料实测校准、节能结论、全年动态验证或大型方案性能保证。运行告警与证据见本轮统一汇合记录。程序更新不重写已有方案、组件、配置或结果；新生成输入使用当前代码标记，旧结果仍保留原来的来源。
