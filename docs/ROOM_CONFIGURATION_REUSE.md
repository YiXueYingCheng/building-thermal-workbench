# 跨建筑复用房间配置

进入目标建筑的可编辑方案，打开“房间配置与作息”，展开“配置名称、复用与差异核对”，选择“跨建筑复用房间配置”。

1. 选择来源建筑、原始配置或已保存的配置版本，再选一个来源房间。列表来自本工作区已登记且具有房间使用配置的建筑。
2. 勾选人员、照明、设备中要复用的项目。每项均含工作日、周末各 24 小时。可以按用途筛选后一并选中，也可以跨用途点选目标房间。
3. 确认单位。保留源单位会分别沿用每间总量或面积密度。保留来源每间实际值会让每间目标房取得相同小时总量。按来源面积密度换算会依目标面积缩放。源单位尚待核实时，选择后两种方式之一。
4. 预览房间差异，确认后加入草稿。可在本页撤销本次应用。保存整份房间配置，再保存方案版本。全楼状态可核对每项的来源建筑、配置版本和房间。
5. 对照试算时，从同一建筑派生两个相同时段、气象、步长和运行模式的方案，分别计算。在“对照总览”查看两份已保存结果的期间需求差。

空调房归属、温控、照明入室得热比例等沿用目标配置。新配置版本需显式选用，已有方案继续绑定原来保存的版本。
