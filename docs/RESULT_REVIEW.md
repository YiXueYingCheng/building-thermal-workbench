# 结果警告的核对与用户采用

适用版本：v0.73.12。只计算一月、两日或其他有效时段，可以正常核对结果；无需补算全年，也不要求五层建筑或固定步长。

在计算队列打开结果明细，进入“来源与核查”中的复核入口。平台先检查本次方案、输入、实际时段、输出及日志是否匹配，显示警告原文和核对依据。此步骤不重新计算建筑。

完整性核查通过后，使用者可选择继续保留待复核，或填写审阅人、采用理由、用途范围，勾选确认后“用户审阅后采用”。缺少开发期间私有报告不再阻挡这条通用流程。记录的是使用者的判断，平台不会自动证明警告没有影响。

采用后保留原始结果、原始警告和日志，另存采用记录；比较和导出的表格、结果包及图中保留用户审阅标记，详细理由随导出说明提供。不要将这个标记理解为无警告或已经通过独立科学验证。

计算未成功、严重错误、输出缺失、不完整或校验不一致时，需先处理原因，不能用填写备注代替完整结果。原来已按专用证据接受的历史结果保持原记录。

本次通过隔离副本验证一月及全年结果、采用及重复提交、缺失或改动的文件、缺失输出和严重错误，以及批次/比较导出。没有替使用者采用实际研究结果。最终窗口布局仍需第三方实际体验；这不属于已经完成的跨设备验收。

批量强制采用通道和失败诊断已加入，见 [批量采用与输出时间尺度](BULK_REVIEW_AND_OUTPUT.md)。只有完成且文件与输出完整性通过的待复核项可采用；用户判断和原警告继续保留。升级后可按原绑定复核官方旧版结果，无需重新运行原建筑。
