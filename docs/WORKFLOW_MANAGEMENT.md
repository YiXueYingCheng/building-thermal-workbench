# 作息、方案入口与计算状态

适用版本：v0.73.11 公开预览版。

## 同一个日计划库

从“公用参考库”的日作息入口，或“编辑方案 → 建筑 → 房间与每日作息”的“查找与管理日计划”，都进入同一个管理器。可以按名称、别名和来源筛选，查看单份计划的 24 小时比例、曲线、来源和历史版本。

1. 公用或导入计划保持只读；点击“复制后编辑”，先填写名称并核对曲线，再保存为本工作区计划。
2. 本工作区计划可以“编辑并追加版本”，也可以将编辑另存为新计划。已有版本及其房间引用保持不变。
3. 房间里的“将当前日计划另存入库”也走同一套命名、预览和保存流程，保留来源房间、通道、日期类型和所基于的方案版本。它保存的是当前草稿的比例计划，人数／功率上下限仍属于房间配置。
4. 保存日计划不会自动改变房间。从房间入口打开管理器，选择工作日或周末，再点“选用当前预览版本”；随后保存建筑配置与方案版本。只更换所选的一天。

人员、照明和设备的比例计划均为 0–1；空调可用计划仅接受 0 或 1。实际人数／功率输入要先在房间中明确切换为比例作息，才能采用比例计划。

关闭有修改的日计划时，可继续编辑、保留编辑并关闭，或放弃编辑。筛选、选择和暂存编辑保留在当前网页内；“刷新日计划库”不会清空编辑。**刷新整个网页、关闭标签页或浏览器前，仍须保存未完成的编辑。** 暂存不是文件备份。

停用只隐藏本工作区默认选项，勾选“包含已停用”可以恢复。不会删除快照、改变原工作簿，或改写已保存方案和结果。名称、全部内容及来源完全相同的重复保存可复用现有版本；仅曲线数值相同、名称或用途来源不同的计划不再被合并。既有计划不作批量合并或迁移。

## 工作区只保留简短方案入口

“工作区设置”显示方案数量、来源数量及最多三条最近打开记录。“打开方案库与版本”进入编辑页原有方案库，继续使用搜索、筛选、历史版本和版本备注。最近打开记录保存在当前网页会话中；这项调整不改变方案存储和归档状态。

## 准备、提交与结果分别表示什么

| 状态 | 含义及下一步 |
| --- | --- |
| 已准备 · 未提交 | 有已核对的输入清单，尚无匹配的提交；可继续核对预算后明确提交。 |
| 已提交 | 已找到关联批次，查看其排队、计算或暂停进度。 |
| 历史安排 · 关联队列已结束 | 准备记录对应的任务已经结束，记录折叠保留，可展开查看关联批次。 |
| 关联待核对 | 清单缺失、校验不符、关联信息不完整或仅部分算例有提交；先核对，不按“未提交”再次提交。 |

计算结束不代表结果已经接受。失败、中断、取消、待复核仍分别显示；结果是否可用于对照或逐日翻面参考，仍由原有结果核验决定。多个批次分别保留，不自动选择“最好”的一份。

关联核对使用保存版本、输入清单、算例身份及输出要求；仅模型相似并不足以覆盖。对比集已明确绑定的来源结果，还需验证来源版本、批次校验和当前计算条件。普通时段输出不替代全年逐日参考。

方案流程、输入准备窗口、逐日参考和对比集进度共用这套提交状态判断。查看状态不启动模拟，也不改写原准备回执、方案、结果或接受依据。

## 供 Agent 使用的现有接口

接口沿用服务的本机认证与校验，写操作须使用正常会话。不要直接编辑数据库。

| 操作 | 接口与要点 |
| --- | --- |
| 查看日计划及历史 | `GET /api/daily-library`，读取快照的 `id`、`revision`、`sha256`、`editable`、`is_latest`、`hidden`。 |
| 保存／复制日计划 | `POST /api/daily-profiles`：`name`、`content`；追加版本传 `parent`，复制传 `copied_from`，两者互斥。引用包含 `id`、`revision`、`sha256`。先预览 24 个比例和来源，再保存。 |
| 兼容公用作息复制入口 | `POST /api/reference-library/copy-daily` 沿用原参数，内部调用同一个保存流程，保留来源链。 |
| 停用／恢复选用 | `POST /api/daily-library/visibility`：`id`、`hidden`、`expected_revision`；冲突时重新读取，不覆盖他人操作。 |
| 采用到房间 | 使用已有建筑配置保存流程，明确绑定日计划快照与工作日／周末，再保存方案。库保存接口本身不采用。 |
| 读取计算准备状态 | 原方案流程、输入准备、逐日工作流和对比集进度接口新增 `lifecycle`／`preparation_history`。历史记录用于查看，不作为再次提交指令。 |

对比集准备回执的 `can_submit` 指示是否还有可明确提交的项目；`lifecycle.finished` 只表示关联队列结束。`lifecycle.batches` 保留匹配批次及匹配依据。缺失或校验异常显示为待核对，不推定为零结果或未提交。

本轮没有调整材料算法、计算输入格式、结果接受规则，也没有重跑全年模拟。公开发布与开发侧回流另行安排。
