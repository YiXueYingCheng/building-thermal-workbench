# 本地安装与升级验收

以下记录对应安装基线 v0.73.11-install-check.1。当前 v0.73.11 在其基础上补充发布/升级文档、已授权公用库分发选择及独立修补版示例，发布前的安装基线验收与当前发行版范围请区分阅读。候选基于过渡版通用功能，附带已验证的 HTTP 并发连接和空工作区只读查询修补；不迁入开发版专用实体 ECA 算法。

新安装使用全新 64 位 Python 3.12 虚拟环境，从 requirements-lock.txt 安装 13 项依赖。无引擎、无方案时可启动空工作区；计算需另行安装并登记指定 EnergyPlus。运行环境检查和两个长沙两日固定状态算例通过，比较 CSV 及 PNG/PDF/SVG 导出通过。

v0.72.2 由原公开 ZIP 解压后建立独立测试数据，再在同一路径升级。升级前停止该副本服务、确认无进行中计算并备份；只更新程序、静态资源和随包参考资料。config.json、data、runs、生成的 assets、虚拟环境和外置结果保持原位。不要把用过的工作区与研究数据当作程序包覆盖，也不要直接用新包的空配置覆盖旧配置。该安装基线使用清单方法；当前随包新增 Upgrade Workbench.cmd，并在独立 v0.72.2 副本完成升级与备份恢复演练，见 [升级验收](UPGRADE_ACCEPTANCE.json)。其他旧版本不自动套用此流程。

原方案与版本、材料版本、比较、结果、旧导出和外置保存位置保留；旧三工况集合仍为三项。版本备注独立保存，不改变计算输入。8 个执行核心文件与 v0.72.2 一致，旧已核对清单仍有效；以后执行代码身份改变时仍须重新准备。新准备相同输入成功复用已有通过核验的结果，无需重复计算。

本机新环境不等于全新 Windows 设备：本轮复用了已安装的 Python、EnergyPlus 和系统字体；尚未替代第三方设备实测。以上安装基线使用原 Drawing26 模板登记；后续已独立验证门洞修补版普通 ACCDB 导入及自然/温控三日计算，见 examples/drawing26-repaired。普通导入的验收覆盖该修补版和装有 Access ODBC 的环境。薄膜、实体材料及可调热阻的能力边界不因本次安装验收扩大；旧模型也不会自动转换为新物性模型。

作息与公用配置库已按作者后续授权纳入发行包；本轮筛选及运行检查见 [分发验收](REFERENCE_DISTRIBUTION_VALIDATION.json)。本目录的历史公开结果、版权和许可继续按各自原声明保留，新增资源不得仅凭本次验收推定可公开。完整升级副本、测试结果和本机路径只在外部验收目录保存。删除和大结果功能不扩展，不自动运行全年算例。

MANIFEST.sha256 对应未使用的原始候选；运行后配置和数据变化不应通过修改清单伪装成原始包。升级用文件清单只作本地验收记录，不能拿新安装清单覆盖旧工作区后当作全目录一致验证。
