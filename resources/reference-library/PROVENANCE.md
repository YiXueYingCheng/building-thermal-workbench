# 随包公用参考库

作者 Zhao Bencheng 于 2026-11-15 明确允许作息和公用配置库随平台公开。本快照包含从用户构建的 ACCDB 中提取、经后续添加修改的公用参考；AI 协助提取整理，不作为额外的数据来源。

当前选择共 1,028 项：897 个材料参考、47 个构造、28 个日计划、48 个全年计划、8 个房间配置。独立的“用户研究材料_10mm”未纳入；6 份其他建筑源数据库和项目 Excel 原文件不随包提供。来源名称、原表编号及校验值只用于追溯。

保留所有已收录条目的原始数值、ID、名称、来源、构造层序及日计划别名；全年计划保留 8760 小时，不归并季节变化。building2 的多份副本作为同一来源系列记录，但不同物性和构造仍按原条目保留，不按名称强行合并。
