用户已于 2026-11-13 授权 Drawing26 作为公开示例建筑、ECA 作为公开示例材料。文件已加入公开源码分发包，已完成长沙两日固定热阻对照及同机异路径复现，并新增两日反馈和31日表面光学切换示例。

## 建筑

源库保存在 [drawing26/Drawing26.accdb](drawing26/Drawing26.accdb)。它是此前已提取核对的“Drawing26 - 副本.accdb”的完整字节副本，仅改了包内文件名。原有名为“Drawing26.accdb”的历史文件是结果库，不能用来代替这份模型库。

**复现本页示例请使用下方 `setup_drawing26.py` 专用入口。** 本次公开包复核发现，源库的一扇门（ID 2892）两侧门洞超出房间侧墙面边界约 71.56 mm，通用 ACCDB 导入会拒绝转换。专用入口沿用已验收的模型模板，并不是现场重跑通用转换；其可计算性不等于这项源几何问题已经修正。详见 [已知限制](../docs/KNOWN_ISSUES.md)。源库和模板保持原样，未平移或缩小门洞。

此次从示例文件重新读取数据库，通过 137 张表的检查：1 个楼层、11 个房间，其中 6 个接空调；房间面积合计 166.935 m²，10 樘门、9 樘窗，无附加遮阳对象。来源和文件指纹见 [source.json](drawing26/source.json)。房间面积合计不是包含墙体的建筑面积。

建筑原作息、内部得热、空调成员及四阈值温控规则保留在源库中。导入时须核对实际用途和地面处理；旧库包含设备得热 40 W/m² 的设置，不应将其默认理解为任意住宅的适用参数。

## 材料

[materials/ECA.json](materials/ECA.json) 保存双状态、单层等效热阻定义，使用既有 ECA 参数：

| 参数 | 蓬松 R | 压缩 C |
| --- | ---: | ---: |
| 热阻，m²·K/W | 0.30284675953967294 | 0.06056935190793458 |
| A 面太阳反射率 | 0.938 | 0.938 |
| A 面发射率 | 0.988 | 0.988 |
| B 面太阳反射率 | 0.176 | 0.176 |
| B 面发射率 | 0.659 | 0.659 |

热阻值与旧配置完全相同，以直接热阻方式输入，可在材料库中分别编辑并保存新版本。状态名称保持独立，不按大小重新命名。太阳吸收率沿用不透明材料的 `1 − 反射率`。

该示例沿用既有不计本等效层蓄热的近似，未加入新材料物理模型。控制规则、参与墙面、朝向与热阻状态分开设置；保存材料本身不会启动反馈控制或计算。

从 v0.72.2 起，材料库直接显示只读的 ECA 内置示例。点击“复制为我的材料”，核对或编辑热阻与光学参数后保存，得到自己的独立材料版本。保存不会自动选入当前方案，采用时仍需预览并保存方案。详见 [公用参考说明](../docs/STARTER_LIBRARY.md)。

以下命令仍可选用：先正常启动工作台一次，再在包根目录运行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\materials\import_eca.py
```

刷新材料库即可查看和编辑。重复运行不会重复添加同一内容，也不会覆盖用户已编辑的材料版本。

## 气象

[weather/sources.json](weather/sources.json) 收录 107 份已有文件的来源和校验值：34 个中国地区，以及 74 点气候代表表中实际有气象文件的 73 点。示例包不含 EPW 原文件，使用时从原提供方取得。

以下命令下载此前已使用的长沙 CSWD 文件。它已选为首个固定热阻对照的气象输入：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\weather\fetch_weather.py --id china34_430000
```

文件保存在 `examples/weather/downloads`，然后通过工作台的气象导入入口选择。查看其他编号可运行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\weather\fetch_weather.py --list
```

下载程序按已登记版本校验文件；来源内容改变时停止，不自动用新数据替换。已有同名而内容不同的文件会保留。气象数据集、引用和本轮验证范围见[气象来源说明](weather/来源说明.md)。

## 建立固定热阻两态示例

此入口登记已核对的 Drawing26 专用模板，不依赖旧平台目录或历史结果。模板含 58 个必要作息文件和 2 个模型；普通 ACCDB 导入入口继续用于普通建筑转换。

完成安装、下载长沙气象并登记引擎后，在包根目录运行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\setup_drawing26.py --weather .\examples\weather\downloads\CHN_Hunan.Changsha.576870_CSWD.epw
```

尚未登记引擎时加上 `--engine "实际安装目录\energyplus.exe"`。该命令检查来源、建立两份方案和比较关系，不启动计算；重复运行复用登记，不覆盖已有版本。应在独立新工作区使用，旧平台来源或同名来源冲突会停止。

登记后重新启动工作台，让页面载入新示例。在方案库依次选择“Drawing26 示例 · 蓬松 · 长沙两日”和“Drawing26 示例 · 压缩 · 长沙两日”，核对计算安排、准备输入并提交。两批完成后打开“Drawing26 · ECA 两态热阻对照”，左右分别选择对应方案的实际计算批次，查看比较并导出。

设置为长沙、1 月 1—2 日、5 分钟步长、温控模式，保留原房间配置与四阈值温控。14 段外墙均铺设 ECA；原参与组的 7 段在 R/C 间对照，其余 7 段保持 R，固定 A。本例不启用反馈或表面光学切换。

参与组为 `S_272`、`S_422`、`S_512`、`S_691`、`S_788`、`S_983`、`S_1118`。两组只改变这些墙的固定热阻状态。模板沿用来源空调、得热与作息；不是对任意新建筑开放 ECA 应用的通用转换器。材料库中编辑保存新版本后，应在另存方案时明确选择该版本；不会追溯修改已保存的示例。

## 两日热阻反馈与31日表面光学切换

在已完成前述 Drawing26 登记的工作区运行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\setup_controls.py
```

这会建立“热阻反馈 · 长沙两日”、与固定 R/C 的比较关系，以及“光学切换日历全年参考”方案，不自动计算。重启工作台后，可在“工作区说明”的示例卡片中直接打开方案。

反馈沿用原 7 段参与墙、18/26 °C 阈值、1 W/m² 热流死区、60 分钟最短保持，初始 C、每个 5 分钟求解步更新；其余 7 段保持 R，固定 A。按普通输入与队列流程运行，分别与已有固定 R/C 两日结果比较。

表面光学切换需要完整的全年原构造逐日参考：打开“光学切换日历全年参考”，在工况的逐日参考入口检查并准备逐日清单，提交队列；完成核验后再运行：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 .\examples\setup_controls.py --orientation
```

程序重新核对参考、规则与源文件；仅在日历可采用且存在切换时，创建切换日前后31日的固定 A和表面光学切换两份方案。当前长沙结果为 4 月 20 日—5 月 20 日，5 月 5 日 B→A；14 段墙均固定 R。若参考缺失、未通过、来源变化或季节不确定，会停止并说明原因，不借用其他建筑日历。

两份31日方案仍需显式准备输入并运行，比较关系自动建立。材料反馈与表面光学切换分别演示；不要将局部时段对比解释为全年节能率。已验证数值、状态占比和结果文件见[新增示例验收报告](../验收结果/Drawing26-反馈与翻面/验收报告.md)。
